PRAC 01 Individual & Combined Transfer Functions
// series() · parallel() · feedback()
▾
MATLAB 
clc; clear; close all;
s = tf('s');

disp('--- Individual Transfer Functions ---');
G1 = 1/(s + 1)
G2 = 2/(s + 2)

disp('--- Overall Transfer Function (Series) ---');
series(G1, G2)

disp('--- Overall Transfer Function (Parallel) ---');
parallel(G1, G2)

PRAC 02 Step Response
// Fixed: 2*z*w (missing multiplication operators)
▾
MATLAB 
clc; clear; close all;
w = 5;
z = 0.5;

sys = tf(w^2, [1  2*z*w  w^2]);
disp('Transfer Function:');
sys

[y, t] = step(sys);
figure;
plot(t, y, 'k', 'LineWidth', 3);
grid on;
title('Unit Step Response');
xlabel('Time');
ylabel('Amplitude');

i = stepinfo(sys);
disp('--- Unit Step Response Parameters ---');
fprintf('Rise Time     = %.4f sec\n', i.RiseTime);
fprintf('Peak Time     = %.4f sec\n', i.PeakTime);
fprintf('Settling Time = %.4f sec\n', i.SettlingTime);
fprintf('Overshoot     = %.2f %%\n',   i.Overshoot);
Fix applied: 2zw → 2*z*w and Kw^2 → K*w^2 (MATLAB requires explicit * for multiplication between variables).
PRAC 03 Steady State Errors

▾

clc; clear; close all;
syms s;
G_s = 10 / (s * (s + 2));
disp('Symbolic TF:'); pretty(G_s);

s  = tf('s');
G  = 10 / (s * (s + 2));
kp = dcgain(G);
kv = dcgain(s * G);
ka = dcgain(s^2 * G);

fprintf('\nSTEADY STATE ANALYSIS\n\n');
fprintf('Position error constant    = %g\n', kp);
fprintf('Velocity error constant    = %g\n', kv);
fprintf('Acceleration error const   = %g\n\n', ka);
fprintf('Unit Step error            = %g\n', 1/(1 + kp));
fprintf('Ramp error                 = %g\n', 1/kv);
fprintf('Parabolic error            = %g\n', 1/ka);
Fix applied: sG → s*G and s^2G → s^2*G. The "No IF" trick works because 1/Inf = 0 naturally in MATLAB — no isinf() checks needed.
PRAC 04 Parameter Variation
// Fixed: K*w^2, 2*z*w, 2*Z*w, 2*z*W (all multiplication)
▾
MATLAB 
clc; clear; close all;
w = 5;
z = 0.5;

% --- LOOP 1: Vary Gain K ---
figure; hold on;
for K = [1 5 10]
    step(tf(K * w^2, [1  2*z*w  K*w^2]));
end
legend('K=1', 'K=5', 'K=10');
title('Effect of Gain K'); grid on;

% --- LOOP 2: Vary Damping Ratio Z ---
figure; hold on;
for Z = [0.2 0.5 0.8]
    step(tf(w^2, [1  2*Z*w  w^2]));
end
legend('\zeta=0.2', '\zeta=0.5', '\zeta=0.8');
title('Effect of Damping Ratio \zeta'); grid on;

% --- LOOP 3: Vary Natural Frequency Wn ---
figure; hold on;
for W = [2 5 8]
    step(tf(W^2, [1  2*z*W  W^2]));
end
legend('\omega_n=2', '\omega_n=5', '\omega_n=8');
title('Effect of Natural Frequency \omega_n'); grid on;
Fix applied: All implicit multiplications made explicit. Loop 1 denominator uses K*w^2 (varying with K). Loops 2 & 3 keep w^2 or W^2 constant as appropriate.
PRAC 05 Root Locus
// Complete — click the plot to select gain K
▾
MATLAB 
clc; clear; close all;
G = tf(1, [1 7 10 0]);

figure;
rlocus(G);
grid on;
title('Root Locus');

disp('Click a point on the root locus plot to select gain K...');
[K, p] = rlocfind(G);

disp('Selected Gain K:'); disp(K);
disp('Closed-Loop Poles:'); disp(p);

T = feedback(K * G, 1);
figure;
step(T);
grid on;
title('Closed-Loop Step Response');

disp('Step Response Parameters:');
disp(stepinfo(T));
Note: rlocfind(G) pauses execution and waits for you to click the root locus plot. MATLAB highlights the selected point and returns the corresponding K and closed-loop poles.
PRAC 06 Lead Compensation
// Complete — series(Gc,G) + stepinfo comparison
▾
MATLAB 
clc; clear; close all;

G  = tf(10, [1 1 0]);
Gc = 0.9 * tf([1 1], [1 3]);  % Lead compensator

T1 = feedback(G, 1);
T2 = feedback(series(Gc, G), 1);

figure;
step(T1, 'r', T2, 'b');
grid on;
legend('Uncompensated', 'Lead Compensated');
title('Step Response Comparison');

disp('--- Uncompensated ---');
disp(stepinfo(T1));
disp('--- Lead Compensated ---');
disp(stepinfo(T2));
Note: Red = uncompensated, Blue = lead compensated. Lead compensator Gc adds a zero at s=−1 and a pole at s=−3, improving phase margin and transient response.
PRAC 07 Bode Plot
// Added stability verdict from margins
▾
MATLAB 
clc; clear; close all;
G = tf(100, [1 22 40 0]);

figure;
bode(G);
grid on;
title('Bode Plot');

[GM, PM, Wcg, Wcp] = margin(G);

disp('--- Stability Margins ---');
disp('Gain Margin (dB):');       disp(20*log10(GM));
disp('Phase Margin (deg):');     disp(PM);
disp('Phase Crossover (rad/s):');disp(Wcg);
disp('Gain Crossover  (rad/s):');disp(Wcp);

if GM > 1 && PM > 0
    disp('System is STABLE');
else
    disp('System is UNSTABLE');
end
Note: margin(G) returns GM as a ratio (not dB), so 20*log10(GM) converts it. Stability requires GM > 1 (i.e., > 0 dB) AND PM > 0°.
PRAC 08 State Space ↔ Transfer Function
// Complete — tf2ss → ss → ss2tf round-trip
▾
MATLAB 
clc; clear; close all;

n = [1 3];
d = [1 5 6];
G = tf(n, d);

[A, B, C, D] = tf2ss(n, d);
sys = ss(A, B, C, D);

[n2, d2] = ss2tf(A, B, C, D);
G2 = tf(n2, d2);

disp('Original TF:');    G
disp('State-Space:');   sys
disp('Converted TF:');  G2

figure;
step(G, 'r', G2, 'b--');
grid on;
legend('Original TF', 'Converted (SS \rightarrow TF)');
title('Step Response — TF vs State-Space Conversion');
Note: The two step responses overlap exactly (red solid under blue dashed), confirming the TF→SS→TF round-trip is lossless. Both G and G2 should be identical.
